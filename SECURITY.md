# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.x | Yes |
| Earlier than 1.0 | No |

## Reporting a vulnerability

Please report vulnerabilities privately through this repository's **Security** tab using **Report a vulnerability**. If that option is unavailable, open an issue asking for a private contact and leave out all technical details.

Include the affected version, the impact and the steps to reproduce. This is a personal project, so responses are best effort.

## Scope

In scope: the code in this repository and its CI workflow. Out of scope: the TVmaze API and any third-party hosting of this application.

See [docs/SECURITY_AUDIT.md](docs/SECURITY_AUDIT.md) for the latest audit.
